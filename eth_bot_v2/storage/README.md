# Storage

## Overview

The `storage` directory contains all persistent data used by the Ethereum AI Trading Bot. It stores market data, databases, machine learning models, cached files, exports, and backups.

This folder acts as the central storage location for the project.

## Folder Descriptions

### `backups/`

Stores backups of databases, datasets, configuration files, and trained models.

### `cache/`

Contains temporary cached data to reduce API calls and improve application performance.

### `database/`

Stores SQLite databases used by the application.

**Examples**

* ETH.db
* trading.db
* ai.db
* logs.db

### `exports/`

Contains exported files generated by the application.

* CSV
* Excel
* JSON
* Parquet

### `historical/`

Stores historical cryptocurrency market data.

Supported timeframes include:

* Daily
* Hourly
* Minute
* Tick

### `models/`

Stores trained Machine Learning and Reinforcement Learning models.

Examples:

* LSTM
* Transformer
* XGBoost
* Reinforcement Learning

### `processed/`

Contains cleaned, normalized, and feature-engineered datasets ready for analytics and machine learning.

### `raw/`

Stores original downloaded market data before preprocessing.

Data sources may include:

* OHLCV
* Trades
* Order Book
* Funding Rate
* Open Interest
* Liquidations
* On-chain Data
* Cryptocurrency News

### `realtime/`

Stores live streaming market data received from exchange APIs or WebSocket connections.

Examples:

* Live Ticker
* Live Trades
* Live Order Book
* WebSocket Messages

---

## Best Practices

* Never modify raw data directly.
* Keep processed datasets separate from raw datasets.
* Regularly back up important databases.
* Store trained models with version numbers.
* Clean cache files periodically.
* Ignore large generated files in version control when appropriate.

---

## Purpose

The `storage` directory provides a structured, centralized location for all persistent project data, ensuring clean organization, easier maintenance, and scalability as the Ethereum AI Trading Bot grows.
