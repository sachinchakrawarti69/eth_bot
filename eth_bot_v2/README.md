# ETH ML Trading Bot

## Quick Start
1. `pip install -r requirements.txt`
2. Edit `ml_trading/config.py` with API keys
3. `python collect_eth_daily.py`
4. `cd ml_trading && python train_model.py`
5. `python predict.py`
6. `python run_trading.py`

## Test Mode
Set `USE_TESTNET = True` in config.py
